# Contribuição

Use branch própria e pull request. Execute os mesmos gates do README e mantenha mudanças pequenas, com regressão reproduzível para cada correção funcional.

- Não inclua chaves, URLs privadas, dados de pacientes, exports de coleções ou trechos de fontes sem autorização de redistribuição.
- Use conteúdo sintético em testes. Não leia a coleção pessoal ou arquivos de credenciais para executar a suíte.
- Preserve schemas, recibos, limites operacionais, formato CSV e compatibilidade QA/Cloze; mudanças de contrato precisam ser explícitas.
- Perfis de informação são descritivos; não afirme validação semântica, clínica ou eficácia pedagógica a partir de contagens.
- Mantenha imports e testes offline: integrações externas devem ser mockadas.
- Não faça force-push na branch principal nem publique artefatos contendo diretórios de runtime.
